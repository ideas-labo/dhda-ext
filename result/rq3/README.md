# RQ3: Component ablations

The CSV files contain 30-run mMAPE distributions for DHDA and its ablation
variants. This data was stored under the legacy name `rq2-fff`; the directory
has been renamed to match the current paper.

| Column | Paper label |
| --- | --- |
| `dhda_reuse_ALL_model` | DHDA |
| `dhda_no_upper` | DHDA-NU |
| `dhda_no_lower` | DHDA-NL |
| `dhda_no_hybrid` | DHDA-NH |
| `dhda_model8` | DHDA-ICSE |
| `dhda_reuse_wocct_model` | DHDA-NT |

Additional legacy columns are retained because the CSV files are preserved
byte-for-byte.
